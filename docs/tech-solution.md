# 校园美食点评平台技术方案

## 一、微服务架构拆分

### 微服务拆分方案

微服务统一放在 `campus-review-service` 聚合模块下，各服务对应独立可运行的 Spring Boot 应用模块。

#### 1. 用户服务 (user-service)

职责范围：
- 用户注册、登录、注销
- 校园账号验证
- 用户信息管理
- 权限认证
- 令牌发放与验证
- 用户画像构建

核心功能：
- 校园邮箱 / 学号验证
- JWT 令牌生成
- 用户信息 CRUD
- 权限角色管理
- 用户活跃度统计

#### 2. 餐馆服务 (restaurant-service)

职责范围：
- 餐馆信息管理
- 餐馆分类与标签
- 餐馆搜索与筛选
- 餐馆基本信息维护

核心功能：
- 餐馆信息 CRUD
- 分类标签管理
- 多条件搜索
- 地理位置服务
- 餐馆资质审核

#### 3. 评价服务 (review-service)

职责范围：
- 评分管理
- 评论管理
- 楼中楼评论
- 评价图片管理
- 评价审核

核心功能：
- 1-5 星评分系统
- 文字评论 CRUD
- 图片上传与存储
- 评论回复功能
- 评价修改与删除

#### 4. 互动服务 (interaction-service)

职责范围：
- 点赞管理
- 收藏管理
- 分享功能
- 评论互动统计

核心功能：
- 餐馆点赞
- 评论点赞
- 餐馆收藏
- 分享记录
- 互动次数统计

#### 5. 排行榜服务 (ranking-service)

职责范围：
- 各种排行榜计算
- 热度算法实现
- 数据统计分析
- 周期性任务调度

核心功能：
- 最受欢迎餐馆榜
- 本周热门餐馆榜
- 活跃点评人榜
- 评分排行榜
- 热度值计算

#### 6. 通知服务 (notification-service)

职责范围：
- 消息推送
- 系统通知
- 评论回复通知
- 活动提醒

核心功能：
- 站内消息
- 邮件通知
- 推送通知
- 消息历史管理
- 通知设置

#### 7. 风控服务 (risk-control-service)

职责范围：
- 作弊检测
- 异常行为监控
- 内容审核
- 反刷机制

核心功能：
- 同 IP 频率限制
- 异常评分检测
- 恶意评论识别
- 刷赞刷评防范
- 违规内容过滤

#### 8. 后台管理服务 (admin-service)

职责范围：
- 后台管理界面
- 数据统计报表
- 系统配置管理
- 内容审核
- 用户封禁

核心功能：
- 餐馆管理后台
- 评论审核后台
- 用户管理后台
- 数据可视化
- 系统监控
